## Como publicar no Netlify

1. Faça upload deste repositório no GitHub
2. No Netlify: **Add new site** → **Import from Git**
3. Escolha o repositório
4. Em **Publish directory** deixe em branco ou coloque `.`
5. Deploy

Ou arraste a pasta inteira no Netlify (Deploy manually).

O arquivo principal é o `index.html` na raiz.
